<task type="auto">
  <name>Task 2: Create bin/env.sh CLI with all subcommands</name>
  <files>bin/env.sh</files>
  <action>
Create `bin/env.sh` as a standalone executable bash script. This replaces the existing `bin/setup.sh` and `bin/generate-config.sh` as the primary configuration tool. Do NOT delete the old scripts yet -- that happens in cleanup.

**Script structure:**

```bash
#!/usr/bin/env bash
```

Use `set -euo pipefail`. The script must be run from the project root directory (detect via presence of `pom.xml.template` or `bin/env-templates.list`).

**Colored output helpers:**
- `green()` for success messages
- `red()` for error messages
- `yellow()` for warnings
- Use ANSI escape codes. Disable colors if stdout is not a terminal (check `[ -t 1 ]`).

**Root directory check:**
At the top of execution (except for `help`), verify the script is running from the project root. Check for the presence of `bin/env-templates.list`. If not found, print red error: "Error: Must run from project root directory" and exit 1.

**Subcommands (implement via case statement on `$1`):**

1. **`load`** -- Special: designed to be sourced (`source ./bin/env.sh load`)
   - Source `.env` file if it exists (using `set -a` / `source .env` / `set +a` pattern)
   - If `.env` does not exist, print yellow warning: ".env file not found. Create it from .env.example"
   - After loading, validate that all required variables from `.env.example` are present (parse .env.example for variable names, check each is set in the environment). Print yellow warning for each missing variable.
   - Print green: "Environment loaded: N variables from .env"
   - IMPORTANT: When invoked as `source ./bin/env.sh load`, the exports must persist in the caller's shell. When checking if being sourced, use `return 0 2>/dev/null || exit 0` at the end.

2. **`show`** -- Display all loaded variables
   - Parse `.env.example` for variable names
   - For each variable, print `VARIABLE_NAME=value` (the current value from environment, or `[not set]` if unset)
   - Plaintext output, no masking (developer tool, per CONTEXT.md)

3. **`substitute-all`** -- Process all templates
   - Read `bin/env-templates.list`, skip comment lines (starting with `#`) and blank lines
   - For each template path:
     - Verify the template file exists (red error and stop if not)
     - Determine output path by removing the `.template` extension
     - Read the template file content
     - Replace all `@VARIABLE_NAME@` occurrences with the corresponding environment variable value
     - If any `@VARIABLE_NAME@` has no corresponding env var set, print red error with the variable name and template file, and exit 1 (stop on first missing variable -- "warns and stops" per CONTEXT.md)
     - Write the output file
     - Print green: "template_path -> output_path"
   - Use `sed` for substitution. Build the sed expression dynamically from all environment variables, or iterate over `@...@` patterns found in each template.
   - After processing all templates, print green summary: "Generated N config files"

4. **`check`** -- Compare template vs generated file timestamps
   - Read `bin/env-templates.list` (same parsing as substitute-all)
   - For each template path:
     - Determine output path
     - If output file does not exist: print yellow warning "output_path: not generated (run substitute-all)"
     - If output file exists but template is newer: print yellow warning "output_path: stale (template modified, run substitute-all)"
     - If output file is up to date: print green "output_path: up to date"

5. **`clean`** -- Remove all generated files
   - Read `bin/env-templates.list`
   - For each template, determine the output path and delete it if it exists
   - Print each deleted file
   - Print green summary: "Cleaned N generated files"

6. **`help`** (also the default when no arguments given) -- Usage information
   - Print usage with all subcommands and one-line descriptions:
   ```
   Usage: ./bin/env.sh <command>

   Commands:
     load            Load .env variables into shell (use: source ./bin/env.sh load)
     show            Display all environment variables
     substitute-all  Generate config files from templates
     check           Check if generated files are up to date
     clean           Remove all generated config files
     help            Show this help message

   Examples:
     source ./bin/env.sh load        # Export variables to current shell
     ./bin/env.sh substitute-all     # Generate all config files
     ./bin/env.sh check              # Check for stale generated files
     ./bin/env.sh clean              # Remove generated files
   ```

**Error handling:**
- Unknown subcommand: print red error with the unknown command, then show help, exit 1
- All errors exit with non-zero status

Make the script executable: `chmod +x bin/env.sh`
