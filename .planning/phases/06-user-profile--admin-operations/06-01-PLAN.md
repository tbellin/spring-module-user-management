  <action>
    **1. Extend UserDto with createdAt field:**
    - Add `java.time.LocalDateTime createdAt` as the last parameter in the record declaration (after `roles`)
    - Update the `from()` factory method to accept and pass `createdAt`
    - Update the Javadoc to include the new parameter

    **2. Update UserService.toUserDto() to pass createdAt:**
    - In `toUserDto()`, add `user.getCreatedAt()` as the last argument to `UserDto.from()`

    **3. Extend UserRepository with JpaSpecificationExecutor:**
    - Add `JpaSpecificationExecutor<AppUser>` to the extends clause: `extends JpaRepository<AppUser, Long>, JpaSpecificationExecutor<AppUser>`
    - Add import for `org.springframework.data.jpa.repository.JpaSpecificationExecutor`

    **4. Create UserSpecifications:**
    - Create new file `src/main/java/com/example/usermanagement/user/internal/UserSpecifications.java`
    - Package: `com.example.usermanagement.user.internal`
    - Create static method `withFilters(String search, String role, String status)` returning `Specification<AppUser>`
    - Search: if search is not blank, create OR predicate matching LOWER(email) LIKE, LOWER(firstName) LIKE, LOWER(lastName) LIKE with `%search.toLowerCase()%`
    - Role: if role is not blank, join `roles` and filter by `name` equals role (e.g., "ROLE_USER" or "ROLE_ADMIN")
    - Status: if status is not blank, map "active" -> enabled=true, "disabled" -> enabled=false
    - Combine all predicates with AND; if no predicates, return `cb.conjunction()`

    **5. Extend UserService with new methods:**
    - `public Optional<UserDto> getUserById(Long id)` -- findById, map toUserDto
    - `public Page<UserDto> findUsers(String search, String role, String status, Pageable pageable)` -- use UserSpecifications.withFilters, call userRepository.findAll(spec, pageable).map(this::toUserDto). Add import for `org.springframework.data.domain.Page`, `org.springframework.data.domain.Pageable`, `org.springframework.data.jpa.domain.Specification`
    - `@Transactional public UserDto updateProfile(String email, String displayName, String firstName, String lastName)` -- find user by email (throw ResourceNotFoundException if not found), set username to displayName if not null/blank (otherwise keep current), set firstName, set lastName, save, return toUserDto. Import ResourceNotFoundException from shared.exception.
    - `@Transactional public UserDto updateUser(Long id, String firstName, String lastName, String roleName)` -- find user by id (throw ResourceNotFoundException), update firstName and lastName, if roleName provided: clear existing roles, find role by name (throw BadRequestException if not found), add role. Save and return toUserDto. Import BadRequestException.
    - `@Transactional public UserDto toggleUserEnabled(Long id, boolean enabled)` -- find by id (throw ResourceNotFoundException), set enabled, save, return toUserDto
    - Note: The class already has `@Transactional(readOnly = true)` at class level; new write methods need explicit `@Transactional`
  </action>
