    **3. Create AdminController (REST API):**
    - Package: `com.example.usermanagement.user.internal`
    - `@RestController @RequestMapping("/api/v1/admin/users")`
    - Constructor inject: `UserService`, `AdminInviteService` (from auth.internal -- the user module's `allowedDependencies = { "shared" }` prevents this import)

    **IMPORTANT MODULE BOUNDARY FIX:** The `user` module cannot depend on `auth` module. AdminController is in `user.internal` but needs `AdminInviteService` from `auth.internal`. Two options:
    - Option A: Move AdminController to `auth.internal` (but then admin controllers are split across modules)
    - Option B: Keep AdminController in `user.internal` and only inject `UserService`. Move the invite call to AdminWebController which would be in `auth.internal`.

    **Best approach:** Place BOTH AdminController and AdminWebController in `auth.internal` (alongside AdminInviteService). The auth module can depend on both user and shared modules. This keeps all admin functionality co-located. The research recommended user.internal but the module boundary constraint makes auth.internal necessary.

    **Revised:** AdminController at `src/main/java/com/example/usermanagement/auth/internal/AdminController.java`

    - `@RestController @RequestMapping("/api/v1/admin/users")`
    - Constructor inject: `UserService`, `AdminInviteService`

    **Endpoints:**

    a) `@GetMapping` -- List users with pagination + search + filter
    - Parameters: `@RequestParam(defaultValue = "") String search`, `@RequestParam(required = false) String role`, `@RequestParam(required = false) String status`, `@PageableDefault(size = 10, sort = "createdAt", direction = Sort.Direction.DESC) Pageable pageable`
    - Call `userService.findUsers(search, role, status, pageable)`
    - Return `ResponseEntity.ok(page)`

    b) `@PostMapping` -- Create user (invite)
    - Parameter: `@Valid @RequestBody CreateUserRequest request`
    - Call `adminInviteService.inviteUser(request.email(), request.role())`
    - Return `ResponseEntity.status(HttpStatus.CREATED).body(userDto)`

    c) `@PutMapping("/{id}")` -- Update user
    - Parameters: `@PathVariable Long id`, `@Valid @RequestBody UpdateUserRequest request`
    - Call `userService.updateUser(id, request.firstName(), request.lastName(), request.role())`
    - Return `ResponseEntity.ok(updatedDto)`

    d) `@PatchMapping("/{id}/status")` -- Toggle enable/disable
    - Parameters: `@PathVariable Long id`, `@RequestBody Map<String, Boolean> body`, `Authentication authentication`
    - **Self-disable prevention:** Get target user via `userService.getUserById(id)`, compare target email with `authentication.getName()`. If same, throw `BadRequestException("Cannot disable your own account")`
    - Call `userService.toggleUserEnabled(id, body.get("enabled"))`
    - Return `ResponseEntity.ok(updatedDto)`

    **Imports needed:** `org.springframework.data.domain.Page`, `org.springframework.data.domain.Pageable`, `org.springframework.data.domain.Sort`, `org.springframework.data.web.PageableDefault`, `org.springframework.http.HttpStatus`, `com.example.usermanagement.shared.exception.BadRequestException`, `com.example.usermanagement.shared.exception.ResourceNotFoundException`, `com.example.usermanagement.shared.dto.UserDto`

    **NOTE:** AdminWebController is placed in `auth.internal` (same as AdminController) due to module boundary constraints.

    **1. Create AdminWebController:**
    - Package: `com.example.usermanagement.auth.internal`
    - `@Controller` (no class-level @RequestMapping)
    - Constructor inject: `UserService`, `AdminInviteService`

    **Endpoints:**

    a) `@GetMapping("/admin/users")` -- List users page
    - Parameters: `@RequestParam(defaultValue = "") String search`, `@RequestParam(required = false) String role`, `@RequestParam(required = false) String status`, `@PageableDefault(size = 10, sort = "createdAt", direction = Sort.Direction.DESC) Pageable pageable`, `Model model`
    - Call `userService.findUsers(search, role, status, pageable)`
    - Add to model: "users" (the Page), "search", "role", "status", "currentPage" (pageable.getPageNumber())
    - Return "admin/users"

    b) `@GetMapping("/admin/users/new")` -- Create user form page
    - Return "admin/user-new"

    c) `@PostMapping("/admin/users/new")` -- Handle create user form submission
    - Parameters: `@RequestParam @NotBlank String email`, `@RequestParam @NotBlank String role`, `RedirectAttributes redirectAttributes`
    - Try: call `adminInviteService.inviteUser(email, role)`, add success Toast flash attribute, redirect to "/admin/users"
    - Catch DuplicateResourceException: add danger Toast, redirect to "/admin/users/new"

    **2. Create admin/users.html template:**
    - Extends layout/default.html via `layout:decorate="~{layout/default}"`
    - Title: "User Management"

    **Search/Filter bar:**
    - Form with `GET` method to `/admin/users`
    - Single search input (name="search") with `th:value="${search}"` placeholder "Search by name or email..."
    - Role dropdown (name="role"): options "All Roles", "ROLE_USER", "ROLE_ADMIN" with `th:selected` based on current role param
    - Status dropdown (name="status"): options "All Status", "active", "disabled" with `th:selected`
    - Search button
    - "Create User" button linking to `/admin/users/new` (right-aligned)

    **Data table:**
    - Bootstrap `table table-striped table-hover` classes
    - Columns: Email, Name, Role, Status, Created, Actions
    - Each row has `data-user-id` attribute set to `th:attr="data-user-id=${user.id()}"`
    - **Display mode cells** (class="display-mode"):
      - Email: `th:text="${user.email()}"`
      - Name: `th:text="${(user.firstName() != null ? user.firstName() : '') + ' ' + (user.lastName() != null ? user.lastName() : '')}"` (trimmed)
      - Role: `th:text="${user.roles()}"` -- extract first role, strip "ROLE_" prefix for display
      - Status: Bootstrap form-switch toggle `<input type="checkbox" class="form-check-input" role="switch" th:checked="${user.enabled()}" th:attr="onchange='toggleUserStatus(this, ' + ${user.id()} + ')'">`
      - Created: `th:text="${#temporals.format(user.createdAt(), 'yyyy-MM-dd')}"`
      - Actions: Edit icon button `onclick="editRow(userId)"`
    - **Edit mode cells** (class="edit-mode d-none") in same row:
      - Email: read-only (just show text)
      - First Name input + Last Name input (replacing Name cell)
      - Role dropdown (ROLE_USER / ROLE_ADMIN)
      - Save + Cancel buttons

    **Pagination:**
    - Show "Showing X of Y users" text
    - Classic numbered pagination (1, 2, 3... N) with prev/next
    - Each page link preserves search, role, status params: `th:href="@{/admin/users(page=${i}, search=${search}, role=${role}, status=${status})}"`
    - Use `th:classappend="${i == users.number} ? 'active'"` for current page highlight
    - Disable prev/next when at boundary

    **JavaScript (in `layout:fragment="scripts"` block):**
    - Read CSRF token from meta tags: `const csrfToken = document.querySelector('meta[name="_csrf"]').content` and `const csrfHeader = document.querySelector('meta[name="_csrf_header"]').content`

    - `editRow(userId)` function:
      - Find row by `data-user-id`
      - Hide `.display-mode` elements (add `d-none`)
      - Show `.edit-mode` elements (remove `d-none`)
      - Pre-populate edit inputs from display values

    - `cancelEdit(userId)` function:
      - Show `.display-mode`, hide `.edit-mode`

    - `saveRow(userId)` function:
      - Collect firstName, lastName, role from edit inputs
      - `fetch('/api/v1/admin/users/' + userId, { method: 'PUT', headers: { [csrfHeader]: csrfToken, 'Content-Type': 'application/json' }, body: JSON.stringify({ firstName, lastName, role }) })`
      - On success: update display cells with new values, toggle back to display mode
      - On error: show alert with error message

    - `toggleUserStatus(checkbox, userId)` function:
      - Get enabled state from checkbox.checked
      - `fetch('/api/v1/admin/users/' + userId + '/status', { method: 'PATCH', headers: { [csrfHeader]: csrfToken, 'Content-Type': 'application/json' }, body: JSON.stringify({ enabled: checkbox.checked }) })`
      - On success: show undo toast (use Bootstrap toast API)
        - Toast message: "User [dis/en]abled" with "Undo" button
        - Auto-dismiss after 8 seconds
        - Undo button reverses toggle: sets checkbox to opposite, calls toggleUserStatus again
      - On error (e.g., self-disable): revert checkbox, show error toast

    - Submit button: "Send Invite"
    - Back link: "Back to Users" linking to `/admin/users`
    - Note text: "An invitation email will be sent to the user with a link to set their password."
