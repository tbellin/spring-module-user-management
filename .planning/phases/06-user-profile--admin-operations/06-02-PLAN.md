    ```java
    @Transactional
    public UserDto inviteUser(String email, String roleName) {
        // Check if email already exists
        if (userRepository.existsByEmail(email)) {
            throw new DuplicateResourceException("User", "email");
        }

        // Find the requested role
        AppRole role = roleRepository.findByName(roleName)
            .orElseThrow(() -> new BadRequestException("Invalid role: " + roleName));

        // Create user with placeholder password (non-matchable BCrypt hash)
        // Use UUID-based placeholder so it never matches any real password
        String placeholder = "$2a$10$INVITE_PLACEHOLDER_" + UUID.randomUUID().toString().replace("-", "").substring(0, 31);
        AppUser user = new AppUser(email, email, placeholder);
        user.setEmailVerified(true);  // Verified by admin invite per CONTEXT.md
        user.setEnabled(true);
        user.addRole(role);
        AppUser saved = userRepository.save(user);

        // Generate password reset token (reuse existing infrastructure)
        String tokenValue = UUID.randomUUID().toString();
        LocalDateTime expiryDate = LocalDateTime.now().plusHours(appProperties.verification().expirationHours());
        PasswordResetToken token = new PasswordResetToken(tokenValue, saved, expiryDate);
        tokenRepository.save(token);

        // Send invite email with set-password link
        String setPasswordUrl = appProperties.verification().baseUrl() + "/reset-password?token=" + tokenValue;
        emailService.sendInviteEmail(email, setPasswordUrl);

        log.info("User invited by admin: {}", email);
        return toUserDto(saved);
    }
    ```

    - Add a private `toUserDto` helper (same as in UserService) since AdminInviteService is in auth module and needs to convert AppUser to UserDto. Alternatively, call `userService.getUserByEmail(email).orElseThrow()` at the end -- this is simpler and reuses existing conversion logic.

    **Simplified approach -- use UserService for DTO conversion:**
    - After saving the user and sending the email, call `userService.getUserByEmail(email).orElseThrow()` to return the UserDto
    - This avoids duplicating the toUserDto conversion logic

    - Import: `DuplicateResourceException`, `BadRequestException` from shared.exception, `UserDto` from shared.dto, `AppUser` from user.internal, `AppRole` from user.internal, `PasswordResetToken` from auth.internal.password
