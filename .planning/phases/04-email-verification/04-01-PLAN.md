<task type="auto">
  <name>Task 1: Configure Spring Mail in application.yml</name>
  <files>src/main/resources/application.yml</files>
  <action>
Add Spring Mail configuration to application.yml with externalized properties:

```yaml
spring:
  mail:
    host: ${MAIL_HOST:smtp.example.com}
    port: ${MAIL_PORT:587}
    username: ${MAIL_USERNAME:}
    password: ${MAIL_PASSWORD:}
    properties:
      "[mail.smtp.auth]": true
      "[mail.smtp.starttls.enable]": true
      "[mail.smtp.connectiontimeout]": 5000
      "[mail.smtp.timeout]": 3000
      "[mail.smtp.writetimeout]": 5000

app:
  mail:
    from: ${MAIL_FROM:noreply@jbeltsolution.com}
  verification:
    expiration-hours: ${VERIFICATION_EXPIRATION_HOURS:24}
    base-url: ${APP_BASE_URL:http://localhost:8080}
```

Add the mail and verification config under the existing `app:` section (after jwt config).

The bracket notation `"[mail.smtp.X]"` is required for Spring Boot to handle property keys with dots.
  </action>
  <verify>Application starts without errors: `./mvnw spring-boot:run -Dspring-boot.run.profiles=dev`</verify>
