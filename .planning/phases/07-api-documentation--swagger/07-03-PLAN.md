Write the following test methods:

1. **`swaggerUiIsAccessibleWithoutAuth`**: GET `/swagger-ui/index.html` returns 302 redirect to the Swagger UI page (springdoc redirects from .html to the actual UI path). Assert status is 3xx (redirect to swagger-ui resources). Alternatively, GET `/swagger-ui/index.html` and follow redirects. The key assertion: the response is NOT 401/403 (security allows access).

2. **`openApiSpecIsAccessibleWithoutAuth`**: GET `/v3/api-docs` returns 200 with `content-type: application/json`. Assert the response contains `"title":"User Management API"`.

3. **`openApiSpecContainsAllApiPaths`**: GET `/v3/api-docs` returns JSON. Parse and assert these paths exist in the `paths` object:
   - `/api/v1/auth/register`
   - `/api/v1/auth/login`
   - `/api/v1/auth/resend-verification`
   - `/api/v1/auth/change-password`
   - `/api/v1/auth/forgot-password`
   - `/api/v1/auth/reset-password`
   - `/api/v1/users/me`
   - `/api/v1/admin/users`
   - `/api/v1/admin/users/{id}`
   - `/api/v1/admin/users/{id}/status`
   Use `jsonPath("$.paths['/api/v1/auth/register']").exists()` style assertions.

4. **`openApiSpecDoesNotContainWebPaths`**: GET `/v3/api-docs` returns JSON. Assert these paths do NOT exist:
   - `/` (home)
   - `/login`
   - `/register`
   - `/admin/users` (web route)
   Use `jsonPath("$.paths['/login']").doesNotExist()` assertions.

5. **`openApiSpecContainsJwtSecurityScheme`**: GET `/v3/api-docs` returns JSON. Assert:
   - `$.components.securitySchemes['Bearer Authentication'].type` equals `"http"`
   - `$.components.securitySchemes['Bearer Authentication'].scheme` equals `"bearer"`
   - `$.components.securitySchemes['Bearer Authentication'].bearerFormat` equals `"JWT"`

Use standard Spring Boot test patterns from this project (see existing test files in src/test). Import `spring-boot-starter-webmvc-test` annotations (per 02-06 decision for Boot 4).
