This is a single atomic operation. All steps must complete before anything can compile.

**Step 1: Replace package/import references in ALL Java files**
```bash
find src -name "*.java" -exec sed -i '' 's/com\.example\.usermanagement/org.jbelt.module/g' {} +
```

**Step 2: Create new directory trees**
```bash
mkdir -p src/main/java/org/jbelt/module
mkdir -p src/test/java/org/jbelt/module
```

**Step 3: Move all contents from old to new tree**
```bash
# Move main sources (preserving subdirectory structure: auth/, user/, shared/)
mv src/main/java/com/example/usermanagement/* src/main/java/org/jbelt/module/
# Move test sources
mv src/test/java/com/example/usermanagement/* src/test/java/org/jbelt/module/
```

**Step 4: Remove old empty directory trees**
```bash
rm -rf src/main/java/com
rm -rf src/test/java/com
```

**Step 5: Update pom.xml (project-level ONLY, NOT parent)**
- Change `<groupId>com.example</groupId>` (line 14) to `<groupId>org.jbelt</groupId>`
- Change `<version>0.0.1-SNAPSHOT</version>` (line 16) to `<version>1.2.0-SNAPSHOT</version>`
- Do NOT touch the parent `<version>4.0.1</version>` on line 10
- Do NOT change `<artifactId>user-management</artifactId>` — it stays as is

**CRITICAL — Do NOT change these:**
- `@ApplicationModule(allowedDependencies = {...})` values like `"user"`, `"shared"` — these are relative module names, not package names
- Any non-Java files (YAML, SQL, templates, Dockerfile, shell scripts) — research confirmed zero references there
