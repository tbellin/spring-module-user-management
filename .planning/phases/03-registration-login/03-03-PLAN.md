    function togglePassword(inputId, button) {
        const input = document.getElementById(inputId);
        const span = button.querySelector('span');
        if (input.type === 'password') {
            input.type = 'text';
            span.textContent = 'Hide';
        } else {
            input.type = 'password';
            span.textContent = 'Show';
        }
    }

  <action>
    1. **Create AuthWebController.java**:
       - @Controller annotation (not @RestController)
       - Constructor injection: AuthService, AuthenticationManager

       **Endpoints:**

       a. `GET /login`:
          - Just return "auth/login" view name
          - Spring Security's form login handles the actual login POST

       b. `GET /register`:
          - Add new RegistrationForm() to model as "registrationForm"
          - Return "auth/register"

       c. `POST /register`:
          - Parameters: @Valid @ModelAttribute("registrationForm") RegistrationForm form, BindingResult result, HttpServletRequest request, RedirectAttributes redirectAttributes
          - IMPORTANT: BindingResult MUST immediately follow @Valid parameter
          - If result.hasErrors(), return "auth/register"
          - Try:
            - Call authService.registerUser(form.getEmail(), form.getPassword(), form.getDisplayName())
            - Manual authentication after registration:
              ```java
              Authentication auth = authenticationManager.authenticate(
                  new UsernamePasswordAuthenticationToken(form.getEmail(), form.getPassword())
              );
              SecurityContextHolder.getContext().setAuthentication(auth);
              ```
            - Add flash attribute: redirectAttributes.addFlashAttribute("toast", new Toast("success", "Welcome! Your account has been created."))
            - Return "redirect:/"
          - Catch DuplicateResourceException:
            - result.rejectValue("email", "duplicate", "An account with this email already exists")
            - Return "auth/register"

    2. **Update SecurityConfig.java** (webFilterChain):
       - Add remember-me configuration:
         ```java
         .rememberMe(remember -> remember
             .key("user-management-remember-me-key")
             .tokenValiditySeconds(7 * 24 * 60 * 60)
             .rememberMeParameter("remember-me")
             .userDetailsService(userDetailsService))
         ```
       - This enables the remember-me checkbox on login form to work
  </action>
