    Create integration tests for REST API endpoints using @SpringBootTest and MockMvc.

    **Test class setup:**
    ```java
    @SpringBootTest
    @AutoConfigureMockMvc
    @ActiveProfiles("dev")
    class AuthControllerTest {
        @Autowired
        private MockMvc mockMvc;

        @Autowired
        private ObjectMapper objectMapper;
    }
    ```

    **Tests to create:**

    1. `register_withValidData_returns201WithJwt()`:
       - POST to /api/v1/auth/register
       - Content-Type: application/json
       - Body: {"email": "newuser@example.com", "password": "password123", "displayName": "New User"}
       - Expect: 201 Created
       - Expect: Response contains "token", "tokenType": "Bearer", "email", "displayName"
       - Use unique email to avoid conflicts with other tests (append timestamp or UUID)

    2. `register_withDuplicateEmail_returns409()`:
       - First register a user
       - POST same email again
       - Expect: 409 Conflict
       - Expect: ProblemDetail response with appropriate message

    3. `register_withInvalidEmail_returns400()`:
       - POST with invalid email format
       - Expect: 400 Bad Request
       - Expect: Validation error for email field

    4. `register_withShortPassword_returns400()`:
       - POST with password < 8 chars
       - Expect: 400 Bad Request
       - Expect: Validation error for password field

    5. `login_withValidCredentials_returns200WithJwt()`:
       - First register a user
       - POST to /api/v1/auth/login
       - Body: {"email": "...", "password": "...", "rememberMe": false}
       - Expect: 200 OK
       - Expect: Response contains "token"

    6. `login_withRememberMe_returnsLongerExpiration()`:
       - Register user
       - Login with rememberMe: true
       - Login with rememberMe: false
       - Compare expiresIn values (rememberMe should be larger)

    7. `login_withInvalidPassword_returns401()`:
       - Register user
       - Login with wrong password
       - Expect: 401 Unauthorized
       - Expect: Generic "Bad credentials" message (SEC-01)

    8. `login_withNonexistentEmail_returns401()`:
       - Login with email that doesn't exist
       - Expect: 401 Unauthorized
       - Expect: Same generic message as wrong password (no user enumeration)

    **Helper method:**
    ```java
    private String registerUser(String email, String password, String displayName) throws Exception {
        var request = Map.of("email", email, "password", password, "displayName", displayName);
        mockMvc.perform(post("/api/v1/auth/register")
            .contentType(MediaType.APPLICATION_JSON)
            .content(objectMapper.writeValueAsString(request)))
            .andExpect(status().isCreated());
        return email;
    }
    ```

    Note: Each test should use unique emails to avoid interference. Use @DirtiesContext(classMode = BEFORE_EACH_TEST_METHOD) if H2 state causes issues, but prefer unique test data instead.
