<task type="auto">
  <name>Task 3: Create AuthService</name>
  <files>
    src/main/java/com/example/usermanagement/auth/internal/AuthService.java
  </files>
  <action>
    Create AuthService in auth.internal package with these methods:

    **Dependencies (injected via constructor):**
    - UserService
    - PasswordEncoder (from shared.config.PasswordConfig)
    - AuthenticationManager
    - JwtService

    **Methods:**

    1. `public UserDto registerUser(String email, String password, String displayName)`:
       - Check if email already exists using `userService.existsByEmail(email)`
       - If exists, throw `DuplicateResourceException("User", "email", email)`
       - Hash password using `passwordEncoder.encode(password)`
       - Create user via `userService.createUser(email, email, passwordHash, displayName, null)`
         - Note: Use email as username (per RESEARCH.md recommendation)
         - displayName goes to firstName field
       - Return the created UserDto

    2. `public Authentication authenticate(String email, String password)`:
       - Create `UsernamePasswordAuthenticationToken` with email and password
       - Call `authenticationManager.authenticate(token)`
       - Return the resulting Authentication
       - Let AuthenticationException propagate (Spring Security handles it)

    3. `public String generateToken(Authentication authentication, boolean rememberMe)`:
       - Extract UserDetails from authentication.getPrincipal()
       - Call `jwtService.generateToken(userDetails, rememberMe)`
       - Return the token string

    4. `public long getTokenExpiration(boolean rememberMe)`:
       - Return the expiration duration in seconds (for AuthResponse)
       - This requires injecting AppProperties or having JwtService expose the values

    Add @Service annotation. Use @Transactional on registerUser method.
  </action>
  <verify>
    `./mvnw compile -q` compiles successfully
  </verify>
  <done>
    AuthService created with registerUser, authenticate, generateToken, and getTokenExpiration methods.
  </done>
