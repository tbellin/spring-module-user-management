<task type="auto">
  <name>Task 1: Create AuthController</name>
  <files>
    src/main/java/com/example/usermanagement/auth/internal/AuthController.java
  </files>
  <action>
    Create AuthController in auth.internal package:

    **Annotations:**
    - @RestController
    - @RequestMapping("/api/v1/auth")

    **Dependencies (constructor injection):**
    - AuthService

    **Endpoints:**

    1. `POST /api/v1/auth/register`:
       - Accepts @Valid @RequestBody RegistrationRequest
       - Call authService.registerUser(email, password, displayName)
       - Call authService.authenticate(email, password) to get Authentication
       - Call authService.generateToken(auth, false) for standard token (registration doesn't use remember-me)
       - Get expiration via authService.getTokenExpiration(false)
       - Build AuthResponse with token, expiresIn, email, firstName (as displayName), roles
       - Return ResponseEntity.status(HttpStatus.CREATED).body(authResponse)

    2. `POST /api/v1/auth/login`:
       - Accepts @Valid @RequestBody LoginRequest
       - Call authService.authenticate(email, password)
       - If successful, extract UserDetails from authentication
       - Call authService.generateToken(auth, rememberMe)
       - Get expiration via authService.getTokenExpiration(rememberMe)
       - Build AuthResponse with token, expiresIn, user info
       - Return ResponseEntity.ok(authResponse)

    **Error handling:**
    - DuplicateResourceException (409) - handled by GlobalExceptionHandler
    - AuthenticationException (401) - handled by GlobalExceptionHandler
    - Validation errors (400) - handled by GlobalExceptionHandler

    Note: GlobalExceptionHandler already handles these exceptions. Don't add try/catch blocks - let exceptions propagate.
  </action>
  <verify>
    `./mvnw compile -q` compiles successfully
  </verify>
  <done>
    AuthController created with /register (201) and /login (200) endpoints returning AuthResponse JSON.
  </done>
</task>
