**Title:** Gmail SMTP Configuration Guide

**Overview:** One sentence explaining this guide covers configuring Gmail as the SMTP provider for sending verification emails, password reset links, and admin invitations.

**Prerequisites table:**
| Requirement | Details |
|-------------|---------|
| Gmail account | Any `@gmail.com` or Google Workspace account |
| 2-Step Verification | Must be enabled on the Gmail account |
| Application configured | `.env` file exists (run `bin/setup.sh` first) |

**Section: Step 1 -- Enable 2-Step Verification**
- URL: https://myaccount.google.com/security
- Navigate to "2-Step Verification" under "How you sign in to Google"
- Follow Google's prompts to enable it (phone number or authenticator app)
- Note: If already enabled, skip to Step 2

**Section: Step 2 -- Generate an App Password**
- URL: https://myaccount.google.com/apppasswords
- Note: This page is only accessible if 2-Step Verification is enabled
- Enter app name (e.g., "UserMgmt" or "Spring Boot App")
- Click "Create" (or "Generate")
- Google displays a 16-character password in groups of 4 (e.g., `abcd efgh ijkl mnop`)
- Copy the password immediately -- it is shown only once
- Note: Spaces in the password are optional; `abcdefghijklmnop` and `abcd efgh ijkl mnop` both work

**Section: Step 3 -- Configure .env**
- Show the exact variables to set with a code block:
```bash
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your-gmail@gmail.com
MAIL_PASSWORD=abcd-efgh-ijkl-mnop
MAIL_FROM=your-gmail@gmail.com
```
- Explain: MAIL_USERNAME is the full Gmail address, MAIL_PASSWORD is the App Password (NOT the Gmail account password), MAIL_FROM should match MAIL_USERNAME (Gmail overrides the From address to match the authenticated account)

**Section: Step 4 -- Verify Email Delivery**
- Start the application: `./bin/run-spring-dev-mode.sh` (or `./bin/run-prod.sh` for Docker)
- Register a new user at http://localhost:8080/register
- Check the registered email inbox for the verification email
- If the email arrives, SMTP is configured correctly

**Section: Troubleshooting**
Table or list format covering:
- `AuthenticationFailedException` -- App Password is wrong, or 2-Step Verification is not enabled. Regenerate the App Password.
- `MailConnectException` / connection timeout -- Firewall or network blocking port 587. Check outbound TCP 587 is allowed.
- `SMTPSendFailedException: 550` -- Sending limit reached. Gmail has a daily sending limit (~500 for personal, ~2000 for Workspace).
- "Less Secure App Access" -- Deprecated by Google in May 2022. App Passwords are the only supported method.
- From address mismatch -- Gmail overrides the From header to match the authenticated account. Use MAIL_FROM matching MAIL_USERNAME, or configure a Gmail alias.

**Section: Alternative SMTP Providers**
Brief paragraph: This application works with any SMTP provider. To use a different provider (Mailgun, SendGrid, Amazon SES, etc.), change MAIL_HOST, MAIL_PORT, MAIL_USERNAME, and MAIL_PASSWORD in `.env` to match the provider's SMTP settings. See `doc/04-deployment.md` for the full production configuration checklist.

**Section: References**
- Link to Google's App Password support page: https://support.google.com/accounts/answer/185833
- Link to `.env.example` in the project for quick variable reference

Do NOT include screenshots (this is a CLI-oriented project). Keep instructions text-based with URLs users can visit.
