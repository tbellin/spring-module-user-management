    All pages use: `layout:decorate="~{layout/default}"` and `layout:fragment="content"`.

    **change-password.html (PAGE-05)** -- Authenticated user changes password:
    - Title: "Change Password"
    - Card layout centered (col-md-6 col-lg-4, same as login/register)
    - Form with `th:action="@{/change-password}"` method="post" (CSRF auto-injected by th:action)
    - 3 fields (per REQUIREMENTS.md -- requires current password):
      1. Current Password: `<input type="password" name="currentPassword" required>`
      2. New Password: `<input type="password" name="newPassword" required minlength="8">`
      3. Confirm New Password: `<input type="password" name="confirmPassword" required minlength="8">`
    - Each field has a show/hide toggle button (same pattern as login page)
    - Error display: `<div th:if="${error}" class="alert alert-danger" th:text="${error}"></div>`
    - Validation errors: `<div th:if="${#fields.hasErrors('*')}" class="alert alert-danger">` -- but since this is not a form-backing object, use `${error}` model attribute instead
    - Submit button: "Change Password" (btn-primary w-100)

    **forgot-password.html (PAGE-06)** -- Request password reset email:
    - Title: "Forgot Password"
    - Card layout centered (same dimensions)
    - Descriptive text: "Enter your email address and we'll send you a link to reset your password."
    - Form with `th:action="@{/forgot-password}"` method="post"
    - 1 field: Email address `<input type="email" name="email" required>`
    - Submit button: "Send Reset Link" (btn-primary w-100)
    - Success message area: `<div th:if="${message}" class="alert alert-success" th:text="${message}"></div>`
    - Error message area: `<div th:if="${error}" class="alert alert-danger" th:text="${error}"></div>`
    - Back to login link: `<p class="text-center mt-3">Back to <a th:href="@{/login}">Login</a></p>`

    **reset-password.html (PAGE-07)** -- Set new password using token:
    - Title: "Reset Password"
    - Card layout centered
    - Form with `th:action="@{/reset-password}"` method="post"
    - Hidden field for token: `<input type="hidden" name="token" th:value="${token}">`
    - 2 fields:
      1. New Password: `<input type="password" name="newPassword" required minlength="8">`
      2. Confirm Password: `<input type="password" name="confirmPassword" required minlength="8">`
    - Show/hide toggle on password fields
    - Error display: `<div th:if="${error}" class="alert alert-danger" th:text="${error}"></div>`
    - Submit button: "Reset Password" (btn-primary w-100)

    **reset-success.html** -- Confirmation after successful reset:
    - Title: "Password Reset Successful"
    - Card layout centered
    - Success icon or alert: `<div class="alert alert-success">Your password has been reset successfully.</div>`
    - Prominent login button: `<a th:href="@{/login}" class="btn btn-primary w-100">Log In</a>` (per CONTEXT.md: no auto-login, show login button)

    **reset-error.html** -- Error page for expired/invalid tokens:
    - Title: "Password Reset Failed"
    - Card layout centered
    - Error message: `<div class="alert alert-danger" th:text="${error}">...</div>`
    - Button to request new reset: `<a th:href="@{/forgot-password}" class="btn btn-primary w-100">Request New Reset Link</a>` (per CONTEXT.md: links back to forgot password form)

    All pages should include the `togglePassword` JavaScript function in a `layout:fragment="scripts"` block where password fields exist (change-password and reset-password pages).
