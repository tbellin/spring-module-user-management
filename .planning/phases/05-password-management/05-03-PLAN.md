    **1. changePassword(String email, String currentPassword, String newPassword):**
    - Look up user by email via userRepository.findByEmail(), throw ResourceNotFoundException if not found
    - Verify currentPassword matches stored hash using `passwordEncoder.matches(currentPassword, user.getPasswordHash())`. If not, throw BadRequestException("Current password is incorrect")
    - Encode new password: `user.setPasswordHash(passwordEncoder.encode(newPassword))`
    - Set timestamp: `user.setPasswordChangedAt(LocalDateTime.now())`
    - Save user
    - `@Transactional` annotation on this method

    **2. requestPasswordReset(String email):**
    - SEC-01 compliance: Silently do nothing if email not found or not verified
    - Check rate limit: `if (!rateLimiter.canResend(email)) return;` -- silently return, don't reveal rate limiting for non-existent emails
    - Look up user: `userRepository.findByEmail(email).ifPresent(user -> { ... })`
    - Only proceed if `user.isEmailVerified()` -- don't help unverified accounts
    - Delete existing reset tokens: `tokenRepository.deleteByUser(user)`
    - Create new token: UUID.randomUUID().toString(), expiry = now + expirationHours
    - Build reset URL: `baseUrl + "/reset-password?token=" + token.getToken()`
    - Send email: `emailService.sendPasswordResetEmail(email, resetUrl)`
    - Record rate limit: `rateLimiter.recordResend(email)` -- after sending email
    - `@Transactional` annotation on this method

    **3. resetPassword(String tokenValue, String newPassword) -> PasswordResetResult:**
    - Follow VerificationService.verifyToken() pattern exactly:
    - Find token: `tokenRepository.findByToken(tokenValue)` -- if empty, return `new PasswordResetResult.Invalid()`
    - Check expired: `token.isExpired()` -- return `new PasswordResetResult.Expired()`
    - Atomic mark as used: `tokenRepository.markAsUsed(tokenValue)` -- if returns 0, return `new PasswordResetResult.AlreadyUsed()`
    - Set new password: encode and set on user
    - Set passwordChangedAt: `user.setPasswordChangedAt(LocalDateTime.now())`
    - Save user
    - Delete all reset tokens for user: `tokenRepository.deleteByUser(user)` -- cleanup
    - Return `new PasswordResetResult.Success()`
    - `@Transactional` annotation on this method

    Use the same `expirationHours` and `baseUrl` from `AppProperties.verification()` (reset tokens use same config as verification tokens). The reset URL path is `/reset-password?token=...` (query parameter, not path variable).


    Add overloaded `isTokenValid` that checks passwordChangedAt:
    ```java
    /**
     * Validates the token against the user details and password change timestamp.
     * Rejects tokens issued before the user's last password change.
     */
    public boolean isTokenValid(String token, UserDetails userDetails, LocalDateTime passwordChangedAt) {
        if (!isTokenValid(token, userDetails)) {
            return false;
        }
        if (passwordChangedAt != null) {
            Date issuedAt = extractIssuedAt(token);
            // Convert LocalDateTime to epoch millis for comparison
            // JWT issuedAt is in seconds, passwordChangedAt is LocalDateTime
            long passwordChangedEpochMilli = passwordChangedAt
                .atZone(java.time.ZoneId.systemDefault())
                .toInstant()
                .toEpochMilli();
            if (issuedAt.getTime() < passwordChangedEpochMilli) {
                return false;
            }
        }
        return true;
    }
    ```
