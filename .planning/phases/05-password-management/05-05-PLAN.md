<task type="auto">
  <name>Task 1: API integration tests for password endpoints</name>
  <files>
    src/test/java/com/example/usermanagement/auth/PasswordApiTest.java
  </files>
  <action>
    Create integration test class following SecurityConfigTest patterns:
    - `@SpringBootTest` + `@AutoConfigureMockMvc`
    - `@MockBean JavaMailSender` to prevent actual SMTP calls
    - Use `SecurityMockMvcRequestPostProcessors.user()` for authenticated requests (same as SecurityConfigTest pattern)
    - Use UUID-based unique test emails for isolation (same as Phase 3 test pattern)

    **Test cases:**

    1. **changePassword_withValidCredentials_returns200** -- Register user, then POST /api/v1/auth/change-password with valid currentPassword and newPassword. Use `.with(user(email).roles("USER"))` for authentication. Assert 200.

    2. **changePassword_withoutAuth_returns401** -- POST /api/v1/auth/change-password without authentication. Assert 401. Since the endpoint is under /api/v1/auth/** (permitAll), and the controller checks authentication explicitly, verify the null-auth handling.

    3. **changePassword_passwordMismatch_returns400** -- POST with newPassword != confirmPassword. Assert 400.

    4. **forgotPassword_existingEmail_returns200** -- POST /api/v1/auth/forgot-password with a registered email. Assert 200 and message contains "If an account exists".

    5. **forgotPassword_nonExistingEmail_returns200** -- POST with non-existing email. Assert 200 with SAME message (SEC-01).

    6. **forgotPassword_rateLimited_returns429** -- POST twice rapidly. Second request should return 429.

    7. **resetPassword_invalidToken_returns400** -- POST /api/v1/auth/reset-password with random token. Assert 400.

    8. **resetPassword_passwordMismatch_returns400** -- POST with mismatched passwords. Assert 400.

    For tests that need a registered user, create the user by POSTing to /api/v1/auth/register, then manually verify the email by updating the user in the database (or use a test helper). Alternatively, use the UserService and UserRepository directly via @Autowired to set up test data.

    Use `JsonMapper` for JSON serialization in requests (same pattern as Phase 3 tests -- `com.fasterxml.jackson.core.json.JsonMapper` for Jackson 3, or use `org.springframework.test.web.servlet.request.MockMvcRequestBuilders` with content type).

    Content type: `MediaType.APPLICATION_JSON`
  </action>
  <verify>Run `./mvnw test -pl . -Dtest=PasswordApiTest -q` to run only this test class. All tests should pass.</verify>
  <done>API integration tests verify: change password (authenticated), forgot password (SEC-01 compliance), reset password (token validation), rate limiting, and password mismatch errors.</done>
</task>
