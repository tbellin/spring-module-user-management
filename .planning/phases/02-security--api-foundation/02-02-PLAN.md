Add JJWT 0.12.6 dependencies for JWT token creation and validation.

**Add to `<properties>` section:**
```xml
<jjwt.version>0.12.6</jjwt.version>
```

**Add to `<dependencies>` section (after spring-boot-starter-security):**
```xml
<!-- JWT (JJWT with Gson backend - avoids Jackson 2/3 conflict in Spring Boot 4) -->
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-api</artifactId>
    <version>${jjwt.version}</version>
</dependency>
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-impl</artifactId>
    <version>${jjwt.version}</version>
    <scope>runtime</scope>
</dependency>
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-gson</artifactId>
    <version>${jjwt.version}</version>
    <scope>runtime</scope>
</dependency>
```

**Critical:** Use `jjwt-gson` (NOT `jjwt-jackson`). Spring Boot 4 uses Jackson 3 by default, and JJWT only supports Jackson 2. Using jjwt-gson sidesteps the conflict entirely.

**Why runtime scope for impl/gson:** These are service provider implementations discovered via ServiceLoader. Only jjwt-api is needed at compile time.

**Create AppProperties.java** in `shared/config`:

```java
package com.example.usermanagement.shared.config;

import org.springframework.boot.context.properties.ConfigurationProperties;

/**
 * Type-safe configuration properties for the application.
 * <p>
 * Properties are bound from the "app" namespace in application.yml.
 * This class uses the Java record-based approach supported in Spring Boot 3+.
 *
 * @param jwt JWT-related configuration
 */
@ConfigurationProperties(prefix = "app")
public record AppProperties(Jwt jwt) {

    /**
     * JWT configuration properties.
     *
     * @param secret       Base64-encoded secret key for signing JWTs (min 256 bits for HS256)
     * @param expirationMs Token expiration time in milliseconds
     */
    public record Jwt(String secret, long expirationMs) {
    }
}
```
