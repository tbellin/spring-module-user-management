## Decisions Made

- **GenerationType.IDENTITY:** Used IDENTITY strategy (not AUTO or SEQUENCE) to match H2's GENERATED BY DEFAULT AS IDENTITY from Flyway schema
- **Two DTOs for different purposes:** UserAuthDto (includes passwordHash for auth module) in user package, UserDto (no sensitive data) in shared.dto
- **Module boundary pattern:** Entities and repositories in `.internal` subpackage (not accessible per Spring Modulith), UserService in package root as public API
- **Entity hashCode using class constant:** Returns `getClass().hashCode()` for transient entities (null id) per JPA best practices
